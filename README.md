# CyberFi Engine

CyberFi masaüstü uygulamasının ajan motoru dağıtım deposu. Sürüm varlıkları, [Happy Agent](https://github.com/slopus/happy-agent) açık kaynak motorunun SHA-256 ile doğrulanmış özgün arşivleridir. Özgün paket biçimi ve varsa çalıştırılabilir dosya imzaları korunur. [Lisans ve telif bildirimi](LICENSE-Happy-Agent.txt).
